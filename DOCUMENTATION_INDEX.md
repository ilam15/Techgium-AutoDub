## 📋 Key Concepts Explained

### **What is AutoDub?**
An AI-powered platform that automatically translates and dubs videos from one language to another while preserving speaker identity and audio quality.

### **How does it work?**
```
Video → Extract Audio → Transcribe → Identify Speakers → 
Translate → Generate Speech → Mix Audio → Merge Video → Done
```

### **What makes it special?**
- **Zero video re-encoding** - Maintains original quality
- **Speaker diarization** - Identifies multiple speakers
- **High-quality TTS** - Natural-sounding voices
- **Fast processing** - GPU-accelerated
- **Free & open-source** - No API costs

### **Tech Stack Summary**
- **Frontend:** React + Vite + TailwindCSS
- **Backend:** FastAPI + Python 3.11
- **AI Models:** Whisper + Pyannote + NLLB + Kokoro
- **Media:** FFmpeg + Audio Separator
